# 財報 memo 術語表

譯法固定，memo 全文一致使用。**不在表上的技術名詞：中譯後首次出現必附英文原文括號**
（例：`分離式推論 (disaggregated inference)`），並把新詞補進本表——錯譯只有帶著原文
才會被讀者與 Step 4 驗證站抓到。

| 英文原文 | 固定譯法 | 備註 |
|---|---|---|
| disaggregated inference | 分離式推論 | prefill/decode 兩階段拆開跑；**不是**「非結構化」(unstructured) |
| coherent pluggable optics | 相干可插拔光模組 | 400G/800G 是埠速率；出貨量單位是「個」，不可與速率融接 |
| scale-up / scale-out / scale-across | 保留英文 | 三者是不同網路層級，各自對應不同產品，不可互換 |
| hyperscaler | 超大規模業者 | |
| service provider | 服務供應商 | 涵蓋 telco、雲端等；**telco（電信商）只是其子集**，兩者數字不同 |
| neocloud | 保留英文 | |
| sovereign AI | 主權 AI | |
| RPO (remaining performance obligations) | RPO（在手合約餘額） | 首次出現寫全稱；≠ backlog |
| ARR | ARR（年度經常性收入） | 季末時點數，不是全年累計數 |
| new logos | 新客戶（logo 數） | 注意單季 vs 全年 |
| backlog | 在手訂單 | |
| design win | 設計勝選 | 注意「本季新增」vs「自推出以來累計」 |
| prepared remarks | 準備稿 | 與 Q&A 數字衝突時以準備稿為準、括號註記 Q&A 說法 |
| wafer-scale | 晶圓級 | |
| pass-through | 轉嫁／由客戶償付 | 依語境 |
| book-to-bill | 保留英文 | |
| memory cost headwind | 記憶體成本逆風 | 漲價歸因用公司字眼，不代換成關稅等外部敘事 |
